# Design Guide & System Specification

This repository contains two design references:

1. **[DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md)**:
   - **General, portable Minimalist Engineering Design System**: Color tokens, typography, zero-clipping border rules, standard form patterns, iconography, and navigation dock architecture.
   - **Drag-and-Drop Ready**: Designed to be pasted or referenced directly in ANY project's `AGENTS.md` or system prompt to redesign any application to this aesthetic.

2. **[SIMPLE_DO_DESIGN_GUIDE.md](./SIMPLE_DO_DESIGN_GUIDE.md)**:
   - App-specific implementation guide covering SimpleDo data structures, tasks, coursework inboxes, habits, day planning shelf, and Firebase synchronization.
